# Current Implementation Plans

This directory holds handoffs with outstanding closure evidence. Closed and
superseded plans move to `../archive/`; closure records remain in `../closure/`.

## Working rules

- Register handoffs before implementation; mark them ready only after hard dependencies are closed.
- Keep decisions in canonical docs or ADRs, and preserve the fixed-target, fail-closed boundary.
- Archive only closed or superseded handoffs; preserve closure evidence and update links.
